# 💬 Sentiment Analysis on App Reviews

NLP project classifying 20,000 app reviews as Positive/Negative.

## 📊 Results
| Model | Accuracy |
|---|---|
| Naive Bayes | 88.55% |
| **Logistic Regression** | **89.42%** ✅ Best |

## 🔍 Key Insights
- Positive words: "love", "great", "awesome", "easy", "perfect"
- Negative words: "deleted", "uninstalled", "waste", "boring", "stupid"
- 20,000 reviews analyzed with 5,000 TF-IDF features

## 🛠️ Tech Stack
Python · NLTK · Scikit-learn · TF-IDF · WordCloud · Matplotlib
